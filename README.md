# Letter Trace

iPad app for tracing upper and lower case letters and numbers 0–9 with a finger or Apple Pencil.

The green dot is saved only when the tracing stays on the shape and covers it. **Clear green dots** asks first, then clears the dots on that iPad.

This is separate from the GitHub Pages site at [scaemrfung/letter-trace](https://github.com/scaemrfung/letter-trace). That page stays up for class.

## Run

```bash
npm install
npm run dev
```
